# ABYSS FRONTIER — 深淵の開拓者

3層の深淵を潜る、ターン制ローグライト。5部屋ごとに待つ「主」を討ち、より深くへ。
スキル・レリック・状態異常を積み上げて、潜行ごとに変わるビルドを組み立てる。

- 完全ブラウザ動作（依存パッケージなし・ビルド工程なし）
- ローカルセーブ＋ローカルランキング（サーバー不要）
- 日付シードの「記録挑戦」で同じ展開に挑める
- ロジックは DOM 非依存の純粋関数群＋ Node 標準テスト

## 遊び方

1. タイトルで「深淵へ潜る」→ クラス（ヴァンガード／アルケミスト／スカウト）を選ぶ。
2. 各部屋（戦闘・精鋭・宝箱・野営地・行商人・出来事・主）を処理する。
3. 戦闘は行動力（◈）を消費するスキル制。敵の行動は予告される。
4. 戦闘後はスキルを1つ獲得／強化（最大6枠・Lv3まで）。精鋭はレリック確定。
5. 第3層の主を討てば踏破。倒れるか踏破でスコアが記録される。

ショートカット: `1`〜`6` スキル / `Space`・`Enter` ターン終了 / `Tab` 対象切替 / `Esc` メニュー

## 構成

```
index.html              エントリ（Cloudflare Pages の配信ルート）
assets/                 アイコン等の静的素材
src/core/rng.js         決定的乱数（シード保存でリロード後も同じ展開）
src/core/data.js        スキル・敵・レリック・イベント等のデータ（バランス調整はここ）
src/core/engine.js      戦闘・進行・報酬・保存の純粋ロジック
src/core/storage.js     localStorage ラッパー（サーバー同期なし）
src/ui/                 描画・入力・効果音
tools/serve.js          開発用の静的サーバー（依存なし）
tests/                  Node 標準テスト + jsdom スモーク
```

## 開発

```bash
npm test          # エンジンのユニット/ファズテスト（Node 標準テスト）
npm run dev       # http://0.0.0.0:4173 で配信
```

UIスモークテストは jsdom を使います（任意。CI ではスキップ可）:

```bash
npm i --no-save jsdom
JSDOM_PATH=./node_modules/jsdom/lib/api.js node tests/ui.smoke.mjs
```

## 公開（Cloudflare Pages）

ビルド工程がないため、リポジトリ直下をそのまま配信できる。

| 項目 | 値 |
| --- | --- |
| ビルドコマンド | （なし／空） |
| 出力ディレクトリ | `/`（リポジトリ直下） |
| 本番ブランチ | `main` |
| プレビュー | 作業ブランチごとの自動プレビュー |

- 限定公開にしたい場合は Cloudflare Access を別途設定する（プレビューURL自体はアクセス制限にならない）。
- ヘッダーは `_headers` で設定。現状スレッド（SharedArrayBuffer）は使っていないため COOP/COEP は不要。
  将来 Godot 等の Web エクスポートを載せる場合は `_headers.sample-coop` を参照。
- ブラウザ保存は端末・ブラウザ単位。削除・容量制限の対象になり得るため、GitHub/Pages では同期されない。

## ロードマップ（運用プランとの対応）

- Phase 1: リポジトリ整備・Web版の起動と保存／再読込確認 ← 本リポジトリで完了
- Phase 2〜4: テストとデプロイの自動化（`.github/workflows/ci.yml`）・プレビュー確認
- Phase 5: 認証・セーブ同期・ランキングのバックエンド（Supabase 案）。現在は `storage.js` の境界のみ
- Phase 6: 独自ドメイン・監視・ロールバック手順

## ライセンス

ゲームコードはリポジトリのライセンスに従う。外部アセットは使用していない（描画はCSSと絵文字、効果音はWebAudio合成）。
