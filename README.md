# CRYSTAL FRONT — Auto Tactics

ドット絵風のビジュアルで進行する、完全自動戦闘のブラウザゲーム画面です。攻撃・スキル使用・次の敵の捕捉・報酬回収はすべて自動で行われます。

## 起動

追加の依存関係はありません。リポジトリのルートで以下を実行して開いてください。

```bash
python3 -m http.server 4173 --bind 0.0.0.0
```

その後、`http://localhost:4173` をブラウザで開きます。

## 操作

- `SPEED`: 自動戦闘の進行速度を x1 / x2 / x4 に切り替え
- 一時停止: バトルの自動進行を停止・再開
- `自動編成`: AI による最適編成を再実行
- `CLEAR`: 戦術ログをクリア

戦闘自体の入力は不要です。敵撃破後は自動で次のエンカウントへ移行します。
